SellersPoint Payment Details

Subscription payments are collected via Paystack checkout - no manual bank details needed.

Pricing Tiers

Set the monthly price for each plan - yearly is automatically 10x monthly (2 months free). Starter is always free; Enterprise is always custom.

Payment Gateway

Choose which payment gateway powers plan upgrades, add-on purchases, and storefront checkout. Only Paystack and Flutterwave support paying sellers out directly from the storefront (split payments) - Stripe covers platform billing only, since direct payouts need Stripe Connect, which isn't set up here.

SellersPoint Logistics

Platform-run delivery, offered alongside a seller's own self/rider delivery. Charged the same way as online payments: a flat fee plus a percentage, added to the order when a seller selects it. API credentials are optional for now while a courier provider is still being evaluated - the fee and toggle work independently of that.

Footer Social Links

Shown as clickable icons in the public landing page footer. Leave blank to hide an icon.

Registration Queue

Businesses mid-flight on CAC incorporation - filed manually until CAC accreditation clears (see SellerPointDocs_Prompt.md).
