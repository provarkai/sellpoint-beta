NRS/FIRS E-Invoicing

Nigeria's e-invoicing mandate (Merchant-Buyer Solution / Electronic Fiscal System) rolled out for large taxpayers from Nov 2025, with medium and small businesses phased in through 2026–2027. Every compliant invoice gets an FIRS/NRS-issued Invoice Reference Number (IRN), a Cryptographic Stamp (CSID), and a QR code before it reaches the buyer — B2B/B2G go through pre-clearance, B2C over ₦50,000 gets reported within 24 hours. Check current NRS guidance for your business's exact compliance deadline.

Build Order — Tax Tools Roadmap

For internal/dev reference. Ship the free Tax Calculator first — as a web app it can go live the moment it's built, no app-store review to wait on — and it validates demand before the paid tier is built.

1
PAYE calculation core

One reusable logic block (Section 30 deductions + Fourth Schedule bands + minimum wage exemption) — every other tool below calls this same function.

2
Free Tax Calculator

Gross + rent + optional deductions → net pay breakdown. Live on the web as soon as it's built, ad-supported.

3
Mini Payroll + Payslip

Multi-employee list reusing the core calc, plus a branded payslip PDF export. First paid tier — replaces manual Excel/accountant work for small business owners.

4
Annual Certificate

Lower-frequency, high-stakes-moment feature (loan/visa/mortgage applications) — a good candidate for a one-time unlock rather than subscription.

5
NRS/FIRS E-Invoicing

Highest build effort — needs UBL/Peppol BIS 3.0 formatting and a live NRS/Access Point Provider integration, not just a local calculation. Build last, once the calculator has real users to convert.
